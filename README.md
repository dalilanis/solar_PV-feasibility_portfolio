## ☀️ Ouarzazate Solar Complex (Morocco)
### PV + CSP Hybrid Feasibility Study

**Type:** Utility-scale hybrid solar (PV + CSP)  
**Focus:** System architecture, performance, and feasibility

### 🔍 Key Work
- Solar resource assessment (high-irradiance desert conditions)  
- PV vs CSP contribution analysis  
- Energy yield & loss evaluation (dust, temperature, thermal losses)  
- Grid integration & dispatchability modeling  
- CAPEX vs long-term performance trade-off analysis  

### 📈 Key Insight
Hybridization improves grid stability but increases system complexity and maintenance sensitivity in desert environments.
